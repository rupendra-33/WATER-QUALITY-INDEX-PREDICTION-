# 🌊 Water Quality Index Prediction Using Machine Learning

## 📌 Project Overview

Water quality plays an important role in protecting human health and the environment. This project focuses on analyzing and predicting the potability of Ganga River water using Machine Learning techniques.

The project uses historical water quality data from 2014 to analyze different water parameters and classify water samples as **Potable (Drinkable)** or **Non-Potable (Not Drinkable)**.

Five Machine Learning classification algorithms are implemented and evaluated to compare their performance and identify the best-performing model.

## 🎯 Objectives

* Analyze water quality data of the Ganga River.
* Perform data cleaning and preprocessing.
* Identify important water quality parameters.
* Apply five Machine Learning algorithms.
* Compare model performance using evaluation metrics.
* Predict whether water samples are potable or non-potable.

## 🛠️ Technologies Used

## 🤖 Machine Learning Models

The following five Machine Learning algorithms are implemented:

1. **Logistic Regression** – Classifies water samples into potable and non-potable categories.
2. **K-Nearest Neighbors (KNN)** – Predicts water quality based on nearby data points.
3. **Naive Bayes** – Uses probability-based classification.
4. **Decision Tree** – Classifies water samples using decision-making rules.
5. **Support Vector Machine (SVM)** – Separates water samples into different categories using a classification boundary.

## 📊 Data Analysis and Visualization

The project includes:

* Water quality distribution analysis.
* Correlation heatmap.
* Dissolved Oxygen (DO) distribution.
* Biochemical Oxygen Demand (BOD) analysis.
* Confusion matrix visualization.
* Actual vs. predicted results comparison.

## 📈 Model Evaluation

All five models are evaluated using the following performance metrics:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

The models are compared based on their F1-scores to identify the best-performing classification algorithm.
